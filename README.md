# MyMelter PWA 1.3.1 DISCOVER

**完全0円ルートを優先した、自分用のチャンネル型Webコンテンツ閲覧PWAです。**

- App Store公開: 不要
- Apple Developer Program: 不要
- GitHub Pages: 無料で利用可能（公開リポジトリ）
- iPhone: Safari → 共有 →「ホーム画面に追加」でアプリ風に起動
- データ: 原則この端末の `localStorage` に保存

## 今回統合した機能

### 採用UI
- チャンネル中心の白＋ブルーのダッシュボード
- ホーム / チャンネル / 履歴 / 保存済み / 設定
- 最近見たもの、保存済み、自動検出候補をホームに表示
- ホーム内に「発見」を追加（新着 / よく見る / 保存）
- ランキングは全ユーザー集計ではなく、この端末の取得・閲覧・保存データだけで算出

### チャンネル
- 追加 / 編集 / 削除
- 動画 / 画像 / 記事 / RSS・Atom / 混在
- CSS selectorの高度な指定
- チャンネル内検索URL
- JSONバックアップ / 復元

### 自動チャンネル発見
サイトURLを1個入力して、以下を候補化します。
- ページ本体
- HTML内で公開されているRSS / Atom
- ナビゲーション内のカテゴリ / タグ / 動画 / 画像 / 記事系リンク
- よくあるFeed URLの検出（`/feed`, `/rss.xml` など）
- `sitemap.xml` が利用できる場合は更新一覧候補
- 候補を1件ずつ追加 / まとめて追加

### メディア閲覧
- 現在動画と前後1本を先読みして、次/前へ移動した際の開始待ちを減らす
- シーク中は指位置に小さなプレビューを追従表示し、可能なら動画フレーム、失敗時はサムネイルで代替
- 動画本体はタップを奪わないレイヤー構成にし、保存・音声・元ページ・シークを最前面操作へ固定
- 「写真に保存」はURL共有ではなくメディア本体をFileとしてiOS共有へ渡すことを優先する
- サムネイルはvideo.twimg.comとpbs.twimg.comの共通メディアIDで対応付ける
- シークはドラッグ中プレビュー、指を離した時に1回だけ実seekして自動再開
- 前後往復時は直近3動画をLRUキャッシュして、同じMP4の再初期化を減らす
- 再生は常に0:00から開始し、前回位置を復元しない
- 失敗動画には個別の「再試行」を表示
- シークはドラッグ中に連続seekせず、指を離した時に1回だけ実行
- 直再生に失敗した動画は、そのフィード中ではWorker経由を優先するルート記憶を使う
- スワイプ中は動画ソースを切り替えず、スクロール停止後に現在動画1本だけをアクティブ化
- 同一動画URLが複数順位に出ても、順位ごとの項目IDを保持して別エントリとして扱う
- twidougaの動画タブは「深掘りフィード」対応
- 現在のランキング一覧は通常一覧として保持し、11〜20位・週間・月間・関連ランキング・取得可能な投稿者別ページは動画タブ専用プールへ分離
- 深掘り項目は重複動画URLを除外し、最大60件を追加
- 一覧から動画を開いた場合も、その位置から深掘りフィード全体へ縦スワイプ可能
- 一覧の「開く」から選択動画の位置で全動画スワイプ再生を開始
- スワイプ再生は現在＋前後1本だけ実ロードし、iPhoneの動画リソースを節約
- 一覧表示
- メディアグリッド
- 直接動画URLを検出できた項目は縦スワイプ動画フィード
- 上スワイプ → 次の動画
- iPhoneの表示可能高さに合わせて1動画=1画面へ補正
- 音声ON/OFF
- 現在時間 / 総再生時間を表示
- 横方向のシークバーで再生位置を変更
- 音声はiPhoneの自動再生制約に合わせ、動画はミュートで確実に開始し「音声ON」で明示的に解除
- 表示中動画のみ自動再生を試行
- 縦スワイプで表示した項目を履歴へ自動記録
- 動画の途中位置を端末内に保存し、次回は続きから再開
- 元ページを開く

### 保存
- 「保存済み」＝MyMelter内ブックマーク
- 保存済みを「リスト（コレクション）」へ複数整理
- 保存済みは新着 / よく見る / タイトル順でも並べ替え
- 端末保存ボタン
- Appleショートカット連携をONにすると、メディアURLを指定ショートカットへ1タップで渡す
- ショートカット未設定時はiOS共有シート等へフォールバック

> 注意: PWAだけではiPhoneの写真ライブラリへ無確認で直接書き込めません。ワンタップに近い運用はAppleショートカット連携を使います。

## GitHub Pagesへ載せる

1. GitHubで公開リポジトリを作成します（例: `mymelter`）。
2. このフォルダの**中身**をリポジトリ直下へアップロードします。
   - `index.html` がリポジトリ直下にある状態にしてください。
3. GitHubの `Settings` → `Pages`。
4. `Deploy from a branch` → `main` → `/(root)` → `Save`。
5. 表示された `https://ユーザー名.github.io/mymelter/` をiPhoneのSafariで開きます。
6. Safariの共有 → `ホーム画面に追加`。

## CORSでサイト解析できない場合

ブラウザにはCORS制限があります。GitHub Pagesから直接読めないサイトを自動解析したい場合は、`worker/worker.js` をCloudflare Workers無料枠へ配置できます。

推奨設定:
1. Cloudflare WorkersでWorkerを1個作成。
2. `worker/worker.js` を配置。
3. Workerの環境変数 `MYMELTER_KEY` に長いランダム文字列を設定。
4. MyMelter → 設定 → Cloudflare Worker URL にWorker URLを入力。
5. MyMelter → 設定 → Workerキー に同じキーを入力。
6. 取得モードを「自動（直接 → Worker）」にします。

WorkerはGETのみで、Cookieを転送せず、ローカル/プライベート宛先を基本的に拒否します。

### Worker 1.1 の403診断
- 通常ブラウザ互換の Accept / Accept-Language / User-Agent で取得します。
- Workerキー不一致、Worker安全ブロック、取得先サイトのHTTP 403/429をMyMelter側で区別して表示します。
- 取得先が403を返した場合でもCAPTCHA・Cookie・認証・IP制限の回避は行いません。
- `https://www.twidouga.net/jp/ranking` が取得先403になった場合だけ、公開されている実ページ `https://www.twidouga.net/jp/ranking_t1.php` を1回だけ自動で試します。
- 代替URLも403なら「サイト側がWorker経由アクセスを拒否」として停止します。

## Safari取り込み（Worker 403サイト）

Worker接続自体が正常でも取得先サイトがHTTP 403を返す場合は、Safariで実際に表示したページからローカル取込できます。

1. MyMelter → 設定 →「取込ブックマークを準備」
2. 「取込コードをコピー」
3. Safariで任意ページをブックマークし、名前を「MyMelter取込」、ブックマークURLをコピーしたコードに置換
4. 対象ページをSafariで開く
5. ブックマーク「MyMelter取込」を実行
6. MyMelterへ戻り、取得した項目をローカルのスナップショットチャンネルとして保存

この方式はWorker/IP経由の取得ではなく、Safari上でユーザーが表示できたDOMから公開リンク・画像・動画候補を抽出します。twidougaではv8取込を使い、1〜10位と11〜20位を同じチャンネルへ統合し、DOMで正しく対応付けた動画を優先して取り込みます。1〜10位と11〜20位を同一チャンネルへまとめ、取り込めた全動画をそのまま連続スワイプ再生できます。1〜10位ページに加えて11〜20位ページも同一オリジンで自動取得します。正規表現リテラルを使わずSafariブックマークURLで崩れにくい方式に変更し、`video.twimg.com` の直接動画URLを優先して候補化します。再生時は設定済みWorkerをメディアストリーミング用に使い、Range要求を転送します。Worker再生が失敗した場合は直URLを1回試します。既存の「MyMelter取込」ブックマークはv3コードへ1回更新してください。ログイン回避、CAPTCHA回避、DRM回避は行いません。

## Appleショートカット保存

MyMelter → 設定 →「Appleショートカットを使う」をONにすると、端末保存ボタンから `MyMelter保存` ショートカットへURLを渡せます。

ショートカット側は概ね以下の構成です。
1. ショートカット入力を受け取る
2. URLの内容を取得
3. 写真アルバムに保存

DRM、アクセス制限、認証回避は対象外です。自分に保存権限がある通常のメディアで使ってください。

## 対応範囲について

MyMelterは公開HTML、RSS/Atom、通常の画像/動画URLを中心に扱います。以下はサイトごとに制限される場合があります。
- ログイン必須コンテンツ
- JavaScriptを実行しないとHTMLに現れない一覧
- 強いBot対策
- DRM動画
- Cookie/認証トークンが必要なメディア

この場合でも、チャンネルを元サイトへのランチャーとして登録できます。
