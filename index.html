GitHub Pagesから直接読めないサイトだけ無料Workerを使えます。キーはこの端末内だけに保存されます。Worker 1.3以上で動画の端末保存に対応します。旧Workerでは保存ボタンから動画を開かない安全動作になります。

Safari取り込み

Worker経由を403で拒否するサイトは、Safariで実際に表示したページから一覧をMyMelterへ戻せます。初回だけ「MyMelter取込」ブックマークを準備します。既に作成済みの場合も、操作・シークプレビューv12へ1回更新してください。

クイック保存

未設定の場合は共有シート／通常ダウンロードへフォールバックします。DRMやアクセス制限の回避は行いません。
